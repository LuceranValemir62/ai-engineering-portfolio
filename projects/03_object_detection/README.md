# Object Detection

A computer vision project for detecting objects in images using deep learning.

---

## Overview

This project builds an object detection pipeline to identify and locate objects inside images.

---

## Goal

Build a complete computer vision workflow including:

- Image preprocessing
- Annotation handling
- Model training
- Inference
- Evaluation
- Visualization

---

## Tech Stack

| Category | Tool |
|---|---|
| Language | Python |
| Vision | OpenCV |
| Deep Learning | PyTorch |
| Detection | YOLO / Detectron2 |
| Visualization | Matplotlib |
