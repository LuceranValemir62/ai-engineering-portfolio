# Generative AI Pipeline

A generative AI project for building text or image generation workflows.

---

## Overview

This project explores generative AI systems using language models, diffusion models, prompt engineering, and model pipelines.

---

## Goal

Build a reproducible generative AI workflow including:

- Prompt design
- Model selection
- Inference pipeline
- Output evaluation
- Safety considerations

---

## Tech Stack

| Category | Tool |
|---|---|
| Language | Python |
| Generative AI | Hugging Face |
| Text Generation | Transformers |
| Image Generation | Diffusers |
| API | FastAPI |
