# Image Classification

A deep learning project for image classification using PyTorch.

---

## Overview

This project trains a convolutional neural network or transfer learning model to classify images into different categories.

---

## Goal

Build a clean deep learning pipeline including:

- Data loading
- Image preprocessing
- Data augmentation
- Model training
- Validation
- Evaluation
- Error analysis

---

## Tech Stack

| Category | Tool |
|---|---|
| Language | Python |
| Deep Learning | PyTorch |
| Vision | TorchVision |
| Experiment Tracking | MLflow |
| Visualization | Matplotlib |
