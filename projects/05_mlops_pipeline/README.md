# MLOps Training Pipeline

An end-to-end machine learning pipeline focused on reproducibility, testing, experiment tracking, and deployment.

---

## Overview

This project demonstrates production-style ML engineering practices.

The goal is to build a pipeline where data, training, evaluation, testing, and deployment are organized and reproducible.

---

## Goal

Build a complete ML engineering workflow including:

- Data validation
- Model training
- Experiment tracking
- Model evaluation
- Testing
- API deployment
- Containerization

---

## Tech Stack

| Category | Tool |
|---|---|
| Language | Python |
| Experiment Tracking | MLflow |
| API | FastAPI |
| Testing | pytest |
